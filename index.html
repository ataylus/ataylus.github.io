Deep Learning · Computational Biology
premise: Protein Fitness Predictor

A diagnostic study of positional memorization in supervised protein fitness predictors, with a validated remedy replicated across two unrelated proteins. Built with PyTorch, HuggingFace's ESM-2 650M foundation model, and BioPython. Private; under review for publication.

Key finding: Mean-pool ESM-2 embeddings cause supervised models to memorize position-fitness mappings from training labels. Per-residue embedding at the mutation site eliminates this without sacrificing accuracy. Switching to per-residue embedding jumps Spearman ρ from 0.038 to 0.271 on MK01_HUMAN.

OMNIS: the partly omniscient auditor

A compliance evidence engine that parses security policies, links evidence to each requirement, tracks freshness, and reports one honest number — the Omniscience Index (0–100). Built solo for the Société Générale iHACK hackathon. Runs fully offline, no API key required.

Key insight: The first thing it audited was the benchmark: a permutation test showed the provided “ground-truth” labels were noise (p = 0.86), so I built a synthetic bench where labels are true by construction and shipped the finding as a reproducible script.

Machine Learning · Biomedical Signal Processing
Myoglyph: sEMG Hand-Gesture Classification

A leak-free classical-ML pipeline classifying hand gestures from forearm surface-EMG for prosthetic control. NinaPro DB2 — 10 subjects, 6 gesture classes, 58,006 windows. Ships an interactive demo that runs on a fresh clone without the dataset.

Key insight: Rebuilt from an earlier course version after finding a test-set leak that inflated the metrics; fixing it lowered KNN macro-F1 from an inflated 0.76 to an honest 0.69. A linear SVM reaches only ~0.39 macro-F1 while the RBF kernel lifts it to ~0.60 — the kernel trick earning its keep on non-linearly-separable EMG classes.

Embedded Systems · HCI
REN-CONSOLE. Gesture-Controlled Arduino Games

Two classic games (Pong + Snake) on a single Arduino UNO R4 hardware setup, controlled entirely by hand gestures via ultrasonic sensors. The Arduino itself hosts a live HTML scoreboard. the microcontroller IS the web server.

The twist: No keyboard, no joystick. Wave your hand left/right to steer Snake. Each HC-SR04 sensor controls a Pong paddle by proximity. Potentiometer for difficulty. Buzzer for audio. Live scoreboard via WiFi.

Quantum Physics · Mesoscopic Transport · Publishable
Non-Hermitian Quantum Transport in Triple Quantum Dots

A semester-long research project on time-domain chiral current in a PT-symmetric triple quantum dot ring. Four deliverables: literature survey, numerical reproduction, analytical synthesis, and a solo End Semester Assessment with 12 computational tasks. I built independent verification suites that caught a real sign-convention bug in the reference work.

Why it matters: I demonstrated dynamical exceptional-point encirclement with direction-dependent mode switching (chirality ratio close to 1.0), previously shown only in photonics. To my knowledge this is the first demonstration for mesoscopic electronic transport, a result we're preparing for submission.
